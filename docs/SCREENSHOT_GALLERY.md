## NPC 主动交谈

NPC 菜单只保留「交谈」：原作任务对白优先，随后在同一个地图底部双立绘框中进入 LLM 连续对话。玩家可逐句推进，也可开启「自由发展」让主角与 NPC 自动承接；角色事实与任务事实不会因模型生成而被改写。
