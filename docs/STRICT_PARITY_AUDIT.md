## 核心矩阵

- 地图：69/69 可加载；400 个事件和实际使用的 5 种 RMXP 指令码均被遍历。
- 互动：215/215 个地图 `Scene_Event` 调用可解析，实际使用类型为
  `0,1,2,4,5,6,7,8,9,10,11,13,14,15,16`；类型 3 和 12 的适配器存在，
  但发行地图没有对应调用，不能把它们计入地图覆盖数量。
- NPC：交谈、查看、常规战斗、交易、拜师、请教与特殊任务分支均由原数据库驱动。
- 战斗：命中、闪避、招架、气血伤害与永久伤势分离、内力、40 个绝招、物品、逃跑、杀/放、掉落、
  道德、悬赏、坛、铸剑和桃花源特殊结算均有运行时实现及分项测试。
- 成长：学习、读书、练功、打坐、冥思、吸气、疗伤、加力、法点、食水、年龄与
  持久化时钟均使用 RGSS 整数截断语义。
- 任务：拜访、寻物、杀人、通缉、石料、三类义工、隐藏交换和九坛链均可执行。
- 生活玩法：钓鱼、游戏厅、铸剑、自制武器、重铸、桃花源房屋与家具均可执行。
- 存档：本地存档与可编辑 JSON 使用同一结构；标题页可以继续、重开或读取 JSON。
- 回归审计：三大任务不会重新抽到已死亡NPC；通缉犯避开玩家当前格并复制法术属性；跨门派拜师、独行大侠请教门槛、白瑞德第六剑和华岳捐赠均按RGSS源码执行。

## 明确的浏览器产品边界

原作依赖 Windows `NetworkSupport.dll` 的联机、联机婚姻和联机对战不属于离线网页
版本，不能在没有服务器协议和原 DLL 的情况下声称“数值不变”。地图也没有 type 12
联机入口调用。除此之外，标题页的“退出游戏”在网页中改为返回标题；密码字段按用户
要求省略。视觉、音频和输入表现属于重绘/网页适配层，不使用原位图。

新增的NPC随机活动、近身对话、群聊、自言自语、动作与战斗叙事属于网页重制增强层。它们通过统一队列调用本地LLM，仅生成展示文本，不能绕过原作事件、任务、战斗与存档结算；人物事实档案用于约束年龄、性别、门派、外貌和武境一致性。

以下属于明确的产品增强而非严格原作等价：地图瓦片全图可穿行；修改器门派与师父可独立设置；玩家经验封顶1000万；静态NPC按战斗武学强化气血、内法力、四维、命中与绝招概率；法术高资源采用递减收益，燃烧使用法力压制差的5%至8%。动态任务敌人仍保留原作的玩家相对生成逻辑。
