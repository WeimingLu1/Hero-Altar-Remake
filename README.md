# 英雄坛说 · 黄金重制

> 文曲星经典《英雄坛说》的浏览器彩色重制版。横版武侠 RPG，包含探索、回合制战斗、门派拜师、任务剧情、生活模拟与终局结局。

## 项目简介

本作采用 Phaser 3 Canvas 2D + TypeScript + Vite 开发。全部美术由代码在运行时程序化生成，零外部资源；DOM 覆盖层负责所有文字界面，呈现水墨纸卷与暗金红烛的武侠风格。

内容规模：

- 七大派：太极、八卦、雪山、花间、尹贺、红莲、丐帮
- 14 个室外区域 + 19 个室内房间
- 50 个 NPC，12 对关系网生活演出
- 三十余个敌人，含黑风寨、六掌门、三终局 BOSS
- 1 条主线 + 12 条支线，3 个终局结局
- 昼夜、天气、随机事件、传闻、恋爱、成亲、宅邸、锻造、存物柜

## 快速开始

```bash
npm install
npm run dev          # 开发服务器 http://127.0.0.1:5173/
npm run build        # 生产构建到 dist/
npm run build:single # 单文件构建到 dist-single/index.html
npm run preview      # 预览生产构建
npm run balance      # 战斗平衡模拟
```

注意：根目录 `index.html` 是 Vite 入口，不要在 `file://` 下直接打开；可直接玩的是 `dist-single/index.html`。

## 操作

- 移动：方向键 / A D
- 交互：E 或回车
- 菜单：1 状态、2 背包、3 武功、4 任务、5 打坐、6 存档
- 舆图：M
- 作弊器：F8

## 通关攻略

### 一句话路线

采药 → 读书识字 10 级 → 打铁拳周三 → 拜师练功并攒 5000 经验 → 领青龙坛地图 → 破黑风寨杀冷铁衣 → 挑战六掌门拿六块石板 → 开启时空尽头 → 选择最终 BOSS 通关。

### 阶段 1：平安镇 + 后山

- 创建角色时四项天赋总和尽量拉满 80，悟性别太低，膂力、根骨、敏捷不低于 15。
- 找村长接主线，去后山采 3 株药草。
- 后山练级：野猪、恶狼、毒蛇；顺手采药、挖矿卖钱。
- 找顾炎武学读书识字到 10 级。
- 找神秘人拿手抄本，练基本内功。
- 支线顺手做：老婆婆义工、马大哈寻物（金钗在后山）。

### 阶段 2：打周三

- 基本拳脚练到 25 级以上，买木刀或铁剑、皮甲、金创药。
- 周三在平安镇内走动，撞上即战，胜利推进主线。

### 阶段 3：拜师 + 成长

- 推荐先入太极门（武当）或八卦门（商家堡），门槛低、成长均衡。
- 门派武功练到 60 级左右解锁绝招，同时学内功、轻功，打坐提升内力强度。
- 散修路线：想拿逍遥心法，先别拜师，集齐拳经、惊天刀谱、焦黄纸页后找镇口无名老者。
- 支线按顺手程度做：捕快缉恶、平一指、玄铁、村长拜访、传书令、武当道童、丐帮日常。
- 攒够 5000 经验前，换青锋剑或金丝大环刀级别武器，以及精制布衣以上护甲。

### 阶段 4：黑风寨

- 5000 经验后找村长领青龙坛地图。
- 路线：山贼 → 山贼头目 → 青龙坛护卫 → 冷铁衣。
- 冷铁衣是第一个真正的 BOSS，开战前存档，备大还丹或大量金创药，善用绝招与运功防御。
- 胜利后拿密信，回村长处交任务。

### 阶段 5：六块石板

- 六位持板掌门：清虚（武当）、王维扬（商家堡）、白瑞德（大雪山）、李青照（百花谷）、和仲阳（冰火岛）、余鸿儒（五指山）。
- 掌门战失败无惩罚，可反复挑战。
- 推荐状态：主力武功 100 级以上、内力强度 400+、玄铁重剑/倚天/屠龙级武器、金锁子甲以上护甲、大量药品。
- 云中鹤悬赏 800 两，夜间后山可打；丐帮乔四海没有石板，可打可不打。

### 阶段 6：终局

- 六块石板集齐后回村长处开启时空尽头。
- 在铜镜前选择最终 BOSS：我是谁、道德和尚、东方求败。
- 道德和尚相对稳，东方求败最难；三个结局各不相同。
- 战前手动存档，备足 5-10 颗大还丹，用绝招 + 防御 + 药品的循环打。

### 提醒

- 存档槽 0 为自动存档，1-3 为手动存档；BOSS 前务必手动存档。
- 按 M 开舆图可传送至已探索区域。
- 普通战斗死亡会银两减半、潜能损失三成；切磋与掌门挑战死亡无惩罚。
- 卡关可用 F8 作弊器；创建角色时名字填 `YOBDC` 可解锁经典黑白模式并赠送资源。
