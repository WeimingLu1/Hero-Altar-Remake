# LPC Open-Source World Library

Downloaded from OpenGameArt on 2026-08-09. All included artwork is distributed
under CC BY-SA 3.0; the complete license and upstream credit files are bundled
beside the images.

Sources:

- LPC Terrains: https://opengameart.org/content/lpc-terrains
- LPC Trees: https://opengameart.org/content/lpc-trees
- LPC Flowers / Plants / Fungi / Wood:
  https://opengameart.org/content/lpc-flowers-plants-fungi-wood
- LPC Walls: https://opengameart.org/content/lpc-walls
- LPC Forest Tiles: https://opengameart.org/content/lpc-forest-tiles

Files named `terrain.png`, `trees.png`, `plants.png`, `walls.png`, and
`forest.png` are unmodified upstream atlases. `semantic-environment.png`
is a project-made 8×8 selection atlas assembled from those sources and the
separately credited LPC house-interior atlas. It does not contain
project-generated artwork.

Runtime use:

- exterior maps use LPC grass, earth, sand, snow, water and stone;
- vegetation is drawn with transparent backgrounds over the same ground tile;
- indoor maps use LPC wooden flooring;
- faction outdoor maps use LPC stone courts;
- walls, trees, flowers and forest props prefer LPC assets.
